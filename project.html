University Dissertation:

Constraining Cosmological parameters via cosmic chronometer data through building a Markov Chain Monte Carlo algorithm in Python.
Technologies used:
Python (Matplotlib, NumPy).
Type of project:
University Dissertation.
Status:
Complete, graded 2:1.

What the project does

The universe is expanding, and cosmologists describe how fast with a small set of numbers called cosmological parameters. This project used measurements from "cosmic chronometers" (very old galaxies whose ages can be used to work out how fast the universe was expanding at different points in its past) to find which values of those parameters fit the data best, and how certain we can be about them.

What I built

  • A Markov Chain Monte Carlo (MCMC) algorithm written in Python. MCMC is a method that takes many guided random steps through the possible parameter values, spending more time where the model fits the data better.
  • Code using NumPy for the calculations and Matplotlib for plotting the results.
