Top Trumps Project:

An interactive top trumps game built using HTML, CSS and JavaScript.
Technologies used:
HTML, CSS and JS
Type of project:
Solo, for fun
Status:
Complete for now. Potential upgrades: introduce an overall score counter over all games played and more stats and a picture added to the card.

What the project does

A playable Top Trumps card game in the browser. You pick a stat on your card and compete against the computer's card to see who wins the round.

What I built

  • The game logic in JavaScript: dealing cards, comparing stats and deciding who wins each round.
  • The card layout and styling in HTML and CSS.
