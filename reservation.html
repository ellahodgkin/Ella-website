Table Reservation System:

A full-stack table reservation system built with Node.js, Express, PostgreSQL, JavaScript, HTML and CSS.
Technologies used:
Node.js, Express, PostgreSQL, JavaScript, HTML and CSS.
Type of project:
Solo, relevant to bar manager job.
Status:
Core features built: full create, read, update and delete (CRUD) for bookings, overlap checking, timezone handling and an admin view.

What the project does

Customers choose a date and time, and the system checks whether a table is free for that slot. If one is, they can make a booking. An admin view lets the venue see and manage all reservations.

I started this because of my job as a bar manager. Bookings are the kind of problem I deal with at work, so I wanted to build something I could test against real needs.

What I built

  • A back end in Node.js and Express that handles requests for creating, viewing, editing and cancelling bookings.
  • A PostgreSQL database that stores tables and reservations.
  • Booking overlap logic, so the same table can't be booked twice for overlapping times.
  • Timezone handling, so booking times stay correct wherever they are stored or displayed.
  • An admin view where the venue can see and manage every reservation.
